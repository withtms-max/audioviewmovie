# 🎬 오디오뷰 영화 목록 자동화 프로그램

엑셀에 적힌 영화 제목들만 가지고 **TMDB API를 활용해 영화 정보(포스터, 장르, 줄거리, 제공 중인 OTT 등)를 자동으로 긁어와서 예쁜 엑셀 양식으로 완성해 주는 프로그램**입니다.

---

## ⚙️ 1. 사전 준비 (처음 다른 컴퓨터에서 세팅할 때 딱 한 번만!)

다른 컴퓨터에서 처음 다운로드 받아 실행하신다면 아래 과정이 필요합니다.

1. **Python 설치**: 컴퓨터에 [Python](https://www.python.org/downloads/)이 설치되어 있어야 합니다. (설치 시 `Add Python to PATH` 체크박스 필수 체크!)
2. **필수 라이브러리 설치**: 다운로드 받은 폴더 안에서 상단 폴더 경로 주소창에 `cmd`를 입력해 검은색 터미널 창을 열고, 아래 명령어를 복사/붙여넣기 한 후 엔터를 칩니다.
   ```bash
   pip install -r requirements.txt
   ```
   이 명령어를 치면 엑셀과 통신을 다루는 필수 프로그램들이 알아서 설치됩니다.

---

## 🚀 2. 초간단 사용 방법 (실제 작업 순서)

폴더 안에 파이썬 파일이 많아 보이지만, 실제로 작업할 때 누르는 메인 순서는 딱 2단계로 매우 단순합니다.

### 📍 Step 1: 자동 데이터 긁어오기 (수집)
1. **(추천)** 폴더에 `movie_list.txt` 메모장 파일을 만들고, 영화 제목을 한 줄에 하나씩 적어넣고 저장합니다. 
   *(또는 기존처럼 `오디오뷰- 목록.xlsx` 파일의 A열 또는 B열에 영화 제목들을 적어넣어도 됩니다.)*
2. 터미널(또는 CMD) 창에서 아래 명령어를 실행합니다.
   ```bash
   python tmdb_fetch.py
   ```
   > 💡 **진행 과정**: 화면에 진행률이 표시되며 `영화_정보_완성.xlsx` 파일이 생성됩니다. API에서 찾지 못한 마이너한 영화들은 줄거리 칸에 "API 정보 없음"으로 표시됩니다.

### 📍 Step 2: 못 찾은 영화들 수동으로 채우기 (선택 사항)
1. 위에서 못 찾은 영화들은 `api없는것들.xlsx` 파일에 엑셀 양식에 맞춰 직접 작성해 둡니다.

### 📍 Step 3: 템플릿에 맞춘 최종 엑셀 파일 만들기
1. 수동 작성까지 끝났다면, 데이터를 하나로 예쁘게 합치기 위해 아래 명령어를 실행합니다.
   ```bash
   python final_format.py
   ```
   > 🎉 **완성!** `영화정보_입력양식_통합본_{생성시간}.xlsx` 파일이 만들어집니다! 이 파일이 포스터 사진까지 깔끔하게 들어간 **최종 결과물**입니다.

---

## 📦 기타 보조 파일들 설명 (참고용)
위의 필수 2개 스크립트 외에 에러 대처 및 부가 기능을 위해 만들어진 파일들입니다. 헷갈리시면 평소에는 무시하셔도 됩니다.

- `tmdb_fetch_resume.py` : 영화가 너무 많아서 데이터 수집 중 인터넷 문제 등으로 멈췄을 때, 코드 안의 숫자를 수정해 **이어서 수집**하는 파일입니다.
- `merge_results.py` : 수집이 중간에 끊겨서 엑셀 파일이 1탄, 2탄으로 나뉘었을 때 하나로 합쳐주는 파일입니다.
- `process_manual_only.py` : 자동 수집 없이 수동 작성본(`api없는것들.xlsx`)만 단독으로 엑셀 양식으로 예쁘게 변환하고 싶을 때 씁니다.
- `rename_posters.py` : 엑셀과 별개로 포스터 이미지만 한 폴더(`영화_포스터_모음`)에 "영화제목.jpg" 로 **일괄 다운로드**할 때 씁니다.
