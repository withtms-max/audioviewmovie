# 🎬 오디오뷰 영화 목록 자동화 프로그램

엑셀에 적힌 영화 제목들만 가지고 **TMDB API를 활용해 영화 정보(포스터, 장르, 줄거리, 제공 중인 OTT 등)를 자동으로 긁어와서 예쁜 엑셀 양식으로 완성해 주는 프로그램**입니다.
윈도우(Windows)와 맥(Mac) 환경 모두를 지원합니다.

---

## ⚙️ 1. 사전 준비 (처음 다른 컴퓨터에서 세팅할 때 딱 한 번만!)

다른 컴퓨터에서 처음 다운로드 받아 실행하신다면 아래 과정이 필요합니다.

### 💻 윈도우 (Windows) 사용자
1. **Python 설치**: 컴퓨터에 [Python](https://www.python.org/downloads/)이 설치되어 있어야 합니다. (설치 시 첫 화면 하단의 `Add Python.exe to PATH` 체크박스 **필수 체크!**)
2. **필수 라이브러리 설치**: 현재 폴더 안에서 상단 폴더 경로 주소창에 `cmd`를 입력해 검은색 터미널 창을 열고, 아래 명령어를 복사/붙여넣기 한 후 엔터를 칩니다.
   ```cmd
   pip install -r system/requirements.txt
   ```

### 🍎 맥 (Mac) 사용자
1. **Python 설치**: 맥은 보통 기본적으로 파이썬이 설치되어 있으나, 없다면 [Python](https://www.python.org/downloads/) 홈페이지에서 Mac용을 받아 설치합니다.
2. **필수 라이브러리 설치**: `터미널(Terminal)` 앱을 열고 이 폴더로 이동한 후(예: `cd Desktop/오디오뷰영화목록`), 아래 명령어를 입력합니다.
   ```bash
   pip3 install -r system/requirements.txt
   ```
3. **실행 권한 부여 (최초 1회)**: 터미널에서 아래 명령어를 입력해 맥용 클릭 실행 파일들에 권한을 줍니다.
   ```bash
   chmod +x 1_영화데이터수집.command 2_최종엑셀만들기.command
   ```

---

## 🚀 2. 초간단 사용 방법 (실제 작업 순서)

터미널이나 명령어를 직접 칠 필요 없이, 폴더 안의 실행 파일을 **더블 클릭**하는 것만으로 동작합니다.

### 📍 Step 1: 영화 제목 입력
- 폴더 안의 **`영화목록.txt`** 메모장 파일을 열고 검색할 영화 제목을 한 줄에 하나씩 적은 후 저장합니다.

### 📍 Step 2: 자동 데이터 긁어오기 (수집)
- **윈도우**: `1_영화데이터수집.bat` 더블 클릭
- **맥**: `1_영화데이터수집.command` 더블 클릭 (또는 우클릭 -> 열기)
> 💡 화면에 진행률이 표시되며 수집이 완료됩니다. `결과물` 폴더에 임시 엑셀 데이터가 만들어집니다.

### 📍 Step 3: 못 찾은 영화들 수동으로 채우기 (선택 사항)
- API에서 찾지 못해 "API 정보 없음"으로 나오는 소수 영화들은 직접 정보를 찾아 채워넣습니다. (건너뛰어도 됩니다)

### 📍 Step 4: 템플릿에 맞춘 최종 엑셀 파일 만들기
- **윈도우**: `2_최종엑셀만들기.bat` 더블 클릭
- **맥**: `2_최종엑셀만들기.command` 더블 클릭
> 🎉 **완성!** `결과물` 폴더 안에 포스터 사진과 모든 정보가 깔끔하게 들어간 **최종 엑셀 결과물**이 생성됩니다!

---

## 📦 구조 설명
- **`영화목록.txt`** : 작업할 영화 제목을 적는 파일
- **`결과물/`** 폴더 : 최종 완성된 엑셀 파일들이 저장되는 곳
- **`system/`** 폴더 : 파이썬 원본 코드들이 담긴 시스템 폴더 (건드리지 않으셔도 됩니다)
