# 🎬 오디오뷰 영화 목록 자동화 프로그램 사용법

이 저장소에 있는 파이썬 스크립트들은 엑셀 파일에 있는 영화 제목들을 기반으로 **TMDB API를 활용해 영화 정보(포스터, 장르, 줄거리 등)를 자동으로 수집하고, 양식에 맞춰 하나의 엑셀 파일로 완성 및 포스터 이미지를 일괄 다운로드**하는 역할을 합니다.

---

## 🚀 파이썬 스크립트 실행 순서 (Workflow)

전체 작업은 크게 **1. API 데이터 수집 -> 2. 수집된 데이터 병합 -> 3. 수동 작업 데이터 처리 -> 4. 최종 양식 통합 -> 5. 포스터 이미지 일괄 다운로드** 순서로 진행됩니다.

### 1️⃣ TMDB API 데이터 수집
- **`tmdb_fetch.py`**
  - **역할**: 원본 엑셀 파일(`오디오뷰-_목록.xlsx`)을 읽어와서 TMDB API에 검색한 뒤 영화 정보를 채웁니다. 첫 번째부터 차례대로 수집하며, 중간에 멈출 경우를 대비해 50개마다 자동 저장됩니다.
  - **출력 파일**: `영화_정보_완성.xlsx`
- **`tmdb_fetch_resume.py`**
  - **역할**: 만약 API 통신 에러나 기타 문제로 스크립트가 중간에 멈췄을 때, 특정 인덱스(예: 200번)부터 이어서 정보를 수집합니다.
  - **출력 파일**: `영화_정보_완성_이어서.xlsx`

### 2️⃣ 수집된 데이터 병합
- **`merge_results.py`**
  - **역할**: 위에서 수집된 두 개의 파일(`영화_정보_완성.xlsx` + `영화_정보_완성_이어서.xlsx`)을 하나로 합쳐줍니다.
  - **출력 파일**: `영화_정보_최종_합본.xlsx`

### 3️⃣ 수동 작업 데이터 처리 (API 정보 없음)
- **`process_manual_only.py`**
  - **역할**: API에서 찾지 못해 사용자가 직접 엑셀로 작성해둔 데이터(`api없는것들.xlsx`)를 읽어와 기본 엑셀 양식(`영화정보_입력양식.xlsx`)에 맞춰 채워 넣습니다.
  - **출력 파일**: `추가영화_정리_완료.xlsx`

### 4️⃣ 최종 양식 통합본 생성
- **`final_format.py`** (추천)
  - **역할**: 병합된 API 데이터(`영화_정보_최종_합본.xlsx`)와 수동 입력 데이터(`api없는것들.xlsx`)를 읽어, 출연진(Cast) 정보를 검색 키워드에 추가하는 등 **최종적인 보강 작업**을 거친 후 지정된 템플릿 양식(`영화정보_입력양식.xlsx`)에 맞춰 통합합니다.
  - **출력 파일**: `영화정보_입력양식_통합본_{생성시간}.xlsx`
- **`combine_all.py`**
  - **역할**: API로 수집 완료된 특정 엑셀본과 `추가영화_정리_완료.xlsx`를 합쳐서 텍스트 데이터 위주의 하나의 마스터 파일을 만듭니다.
  - **출력 파일**: `영화정보_최종_전체합본.xlsx`

### 5️⃣ 포스터 이미지 일괄 다운로드 (선택사항)
- **`rename_posters.py`**
  - **역할**: `영화_정보_최종_합본.xlsx` 파일을 읽고, 정리된 `포스터 URL`을 통해 모든 포스터 이미지를 **"영화 제목.jpg"** 형식으로 이름을 변경하여 한 폴더에 다운로드합니다.
  - **출력 폴더**: `영화_포스터_모음/` (이 폴더 안에 이미지들이 저장됨)

---

## 🛠 사용 방법 (요약)

새로운 영화 목록이 추가되었을 때 전체를 다시 돌리는 흐름은 다음과 같습니다.

1. `오디오뷰-_목록.xlsx` 파일의 두 번째 열에 찾고자 하는 영화 제목을 쭉 나열합니다.
2. 터미널(또는 CMD)에서 `python tmdb_fetch.py` 를 실행합니다. (중간에 끊기면 `tmdb_fetch_resume.py` 사용)
3. 수집이 끝나면 `python merge_results.py` 를 실행해 하나로 합칩니다.
4. API에 나오지 않는 영화들은 `api없는것들.xlsx` 에 수동으로 입력해둡니다.
5. `python final_format.py` 를 실행하여 최종 완성된 엑셀 파일을 얻습니다.
6. 포스터 이미지만 따로 저장해두고 싶다면 `python rename_posters.py` 를 실행합니다.
